# Introduction
Unified Payments Interface (UPI) enables interoperable, near-instant account-to-account payments in India. Fast payment experiences also create challenges for monitoring unusual transaction behaviour at scale. Fraud patterns may involve unusual amounts, rapid transaction bursts, newly added beneficiaries, unfamiliar devices, or coordinated movement of funds.

SentinelPay explores how machine learning can support risk monitoring. It treats each transaction as an event and evaluates both individual attributes and behavioural context. The system is designed as a modular prototype rather than a live payment gateway.
