# Problem Statement
A transaction monitoring team needs timely and explainable signals to prioritize suspicious digital payment activity. Static thresholds may miss combinations of weak indicators and may generate excessive false positives. The project investigates whether a combination of supervised classification, anomaly detection and behavioural features can improve prioritization while maintaining transparent, measurable trade-offs.

**Research question:** How effectively can a reproducible ML pipeline rank synthetic UPI-like transactions by suspiciousness, while controlling false positives and providing interpretable reasons?
