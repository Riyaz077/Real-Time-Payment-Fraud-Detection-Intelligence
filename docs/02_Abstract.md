# Abstract
SentinelPay proposes an AI-assisted framework for identifying suspicious UPI-like payment activity. The prototype combines supervised fraud classification with unsupervised anomaly detection and behavioural transaction features such as amount deviation, transaction velocity, new-beneficiary activity and device novelty. A risk-scoring layer converts model outputs and anomaly signals into review priorities, while explainable reason codes help analysts understand alerts. A FastAPI service exposes prediction functionality and a Streamlit dashboard supports monitoring and investigation. Experiments use synthetic data so that the workflow can be reproduced without exposing personal financial information. The project evaluates precision, recall, F1-score, PR-AUC, false-positive rate and inference latency, emphasizing the operational cost of missed fraud and unnecessary alerts. SentinelPay is an educational decision-support prototype and does not connect to live UPI infrastructure or autonomously authorize transactions.
