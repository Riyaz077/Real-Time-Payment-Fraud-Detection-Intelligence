# Security and Privacy
- Use synthetic or explicitly authorized de-identified data.
- Never collect UPI PINs, OTPs, passwords, full account numbers or authentication secrets.
- Mask or tokenize identifiers; minimize data collection.
- Encrypt data in transit and at rest in any real deployment.
- Apply least privilege, MFA, secrets management and audit trails.
- Define retention, deletion and incident response policies.
- Review model bias and disparate error rates.
- Require human review and a customer dispute/escalation process.
- This educational repository is not a compliance certification.
