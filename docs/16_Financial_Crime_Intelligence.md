# Financial Crime Intelligence
Potential future analytical modules:
- repeated sender-to-receiver relationships;
- bursts across multiple beneficiaries;
- shared synthetic device tokens;
- rapid pass-through patterns;
- connected-component and graph centrality summaries;
- case timelines and analyst notes.

Graph signals can be useful for investigation prioritization, but shared devices or common counterparties are not proof of wrongdoing. Use privacy-preserving identifiers, access controls and documented retention limits.
