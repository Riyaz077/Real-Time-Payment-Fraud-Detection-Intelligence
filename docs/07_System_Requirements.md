# System Requirements
## Functional
FR1 Generate or load transaction events. FR2 Validate required fields. FR3 Compute behavioural features. FR4 Train and persist a model. FR5 Score transactions. FR6 Assign risk bands. FR7 Generate reason-coded alerts. FR8 Show KPIs and suspicious events. FR9 Expose a prediction API.

## Non-functional
Reproducibility, modularity, auditability, privacy by design, low local inference latency, testability and graceful handling of invalid input.

## Hardware/software
Python 3.10+, 8 GB RAM recommended for the starter dataset, Windows/macOS/Linux, Git, and a modern browser.
