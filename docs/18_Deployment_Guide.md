# Deployment Guide
## Local
Install requirements, generate data, train model, run Streamlit and FastAPI in separate terminals.

## Future deployment checklist
Containerize; use managed secrets; TLS; authentication and role-based access; encrypted storage; audit logging; rate limits; monitoring; rollback; model versioning; incident response; backup/restore; data retention controls; load and security testing.

Do not deploy this prototype to process live financial transactions without formal security, legal, privacy, model-risk and operational reviews.
