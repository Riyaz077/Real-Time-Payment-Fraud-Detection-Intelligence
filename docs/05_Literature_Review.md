# Literature Review
## Themes to review
1. Transaction fraud detection under severe class imbalance.
2. Supervised models: Logistic Regression, Random Forest and gradient boosting.
3. Unsupervised anomaly detection: Isolation Forest and Local Outlier Factor.
4. Temporal and graph-based transaction behaviour.
5. Explainability, calibration and human-in-the-loop investigations.
6. Concept drift, adversarial adaptation and privacy-preserving analytics.

## Research gap for this prototype
Many educational examples stop at binary classification. SentinelPay connects classification to risk prioritization, reason-coded alerts, API serving and an analyst-facing dashboard. This is an engineering integration objective, not a claim of novel state-of-the-art detection.

## Suggested reading
Consult the official RBI digital payment security directions and primary papers/documentation for each model. Record authors, year, venue, dataset, metrics, limitations and DOI/URL in a literature matrix before making comparative claims.
